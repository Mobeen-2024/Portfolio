### 3. 🏋️ [RepX AI : Gym Platform](https://github.com/Mobeen-2024/RepX-AI)

  - `repx`: Inspect RepX AI 3D WebGL, 600k Kaggle Polars pipeline, and heuristic scorer.
  - `hisaab`: Inspect Hisaab-Kitaab offline Dexie.js datastore and Gemini voice dictation.

  - `comptia`: Review CompTIA A+ Core 1 & 2 preparation status.
  - `contact`: Print direct telephone, email, and London coordinates.
  - `clear`: Clear the terminal output buffer.
- **Fuzzy Prefix Matching**: Accepts shorthands like `crypto`, `hisaab`, `rep`, `proj`, `hard`, `net`, and `comp`.
- **Keyboard Dismissal**: Press **`Escape`** to instantly minimize the console.

## 🚀 Quick Start

### Prerequisites
Node.js (v18 or higher recommended) and npm:
```bash
node -v
npm -v
```

### 1. Clone & Install
```bash
git clone https://github.com/Mobeen-2024/Portfolio.git
cd Portfolio
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173` (or port indicated in terminal).

### 3. Run Automated Tests
```bash
npm test
```
Executes all 19 unit and integration tests via Vitest in JSDOM.

### 4. Run Code Linter
```bash
npm run lint
```
Runs ESLint with React Hooks and Refresh rules.

### 5. Build for Production
```bash
npm run build
```
Generates minified, tree-shaken production assets into the `dist/` directory in < 3 seconds.
